# TechNova - Company Landing Page

## Description
TechNova is a responsive company landing page
built using HTML5 and CSS3.

## Features
- Responsive navigation bar
- Full-screen hero section
- Three service cards
- Client testimonials
- Contact form
- Responsive footer
- CSS Grid and Flexbox layouts
- Three responsive breakpoints

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Git and GitHub
